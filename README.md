# Email Assistant

Generate smart, professional email replies with Google Gemini — a Spring Boot backend plus a Chrome extension that adds an **Auto Reply** button right inside Gmail's compose window.

## Features
- One-click **Auto Reply** button inside Gmail compose
- Tone selection: professional / friendly / formal / casual
- Replies generated by Gemini and inserted above the quoted email, ready to send
- Reads the email content from Gmail's compose box or reading pane (handles Gmail's async loading)
- Auto-fills the subject (`Re: …`) when Gmail leaves it empty
- API key can be stored server-side (`GEMINI_API_KEY`) or per-request from the extension popup

## Tech Stack
- **Backend:** Java 17 · Spring Boot 4.1.0 · Spring Web MVC + WebClient · Lombok · Maven
- **Model:** Google Gemini (configurable via `GEMINI_URL`)
- **Extension:** Chrome Manifest V3 · vanilla JS · no build step

## Prerequisites
- JDK 17+
- Maven
- A Google Gemini API key — https://aistudio.google.com/apikey
- Google Chrome

## Backend Setup

### 1. Set environment variables
| Variable | Value |
|----------|-------|
| `GEMINI_API_KEY` | Your Gemini API key (can be left blank if you only use the popup key) |
| `GEMINI_URL` | e.g. `https://generativelanguage.googleapis.com/v1beta/models/gemini-3.6-flash:generateContent?key=` |

In IntelliJ: **Run ▸ Edit Configurations ▸ Modify options ▸ Environment variables** (no spaces around `=`, separate with `;`).

### 2. Run
```
mvn spring-boot:run
```
The app starts at `http://localhost:8080`.

### 3. API
`POST /api/email/generate`

Headers:
- `Content-Type: application/json`
- `X-Gemini-Key: <your-key>` (optional — overrides `GEMINI_API_KEY` for that request)

Body:
```json
{
  "emailContent": "The email you want to reply to...",
  "tone": "professional"
}
```
Response: the generated reply as plain text.

## Chrome Extension Setup
1. Open `chrome://extensions`
2. Enable **Developer mode** (top-right)
3. Click **Load unpacked** and select the `extension/` folder
4. Click the extension icon and optionally set:
   - **Gemini API Key** — used for this request (overrides the server key)
   - **Backend URL** — defaults to `http://localhost:8080`
   - **Tone** — default / professional / friendly / formal / casual
5. Click **Save**

## Usage
1. Make sure the backend is running
2. Open an email in Gmail and click **Reply** (or open a new compose)
3. Click the blue **Auto Reply** button in the compose toolbar
4. Gmail auto-fills the subject if needed; a draft reply is inserted above the quoted email — review and hit Send

## Troubleshooting
- **500 Internal Server Error** — Gemini returned an error, usually 503 "model busy". Wait a few seconds and retry, or check `GEMINI_URL` for a stray `=`. The app returns the real Gemini error message instead of a raw 500.
- **Reply has no spaces between words** — caused by unstable model aliases like `gemini-flash-latest`. Pin a stable model (e.g. `gemini-3.6-flash`) in `GEMINI_URL`.
- **Button doesn't appear in Gmail** — Gmail's DOM changes over time. Open the browser console (`[Email Assistant] …` logs) for errors and reload the extension.
- **"No email text found"** — Gmail loads the quoted email asynchronously; the button waits ~5s. If it still fails, the reading-pane fallback extracts the open message directly.
